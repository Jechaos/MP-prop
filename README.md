# PayNu (prop)

Fiktiv betalingsapp til filmbrug. Ingen rigtige betalinger. Beloeb, navn, organisation og nummer skrives ind i menuen og huskes til naeste gang.

## Saadan faar du den paa telefonen

1. Opret et nyt repository paa github.com (fx "paynu-prop"), sat til Public.
2. Klik "Add file" og "Upload files", og traek alle filer og mappen "icons" ind. Tryk "Commit changes".
3. Gaa til Settings, Pages. Vaelg "Deploy from a branch", branch "main" og mappe "/ (root)". Tryk Save.
4. Efter ca. et minut staar adressen i toppen: https://DIT-BRUGERNAVN.github.io/paynu-prop/
5. Aabn adressen i Safari (iPhone) eller Chrome (Android).
   - iPhone: tryk Del og "Foej til hjemmeskaerm".
   - Android: tryk menuen og "Installer app" eller "Tilfoej til startskaerm".

Appen virker offline, naar den foerst er aabnet en gang.

## Filer

- index.html: hele appen
- manifest.webmanifest og sw.js: goer den installerbar og offline
- icons/: appikoner
